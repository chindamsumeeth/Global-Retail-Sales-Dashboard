# Global-Retail-Sales-Dashboard #

# 🔍 About the Project #

This project is a Power BI dashboard created to analyze global retail sales data and present it in a clear and interactive way. The aim is to turn raw data into useful insights that help understand business performance across different regions and products.

# 📈 Key Insights #
Total Sales: 12.64M \
Total Profit: 1.47M \
Profit Margin: 12% \
Return Rate: 2% \
Consumer segment contributes the highest share of sales
Some regions perform better than others in terms of revenue. \
A few countries show negative profit, indicating losses
Sales vary across months, showing seasonal trends
 # 📊 Dashboard Features  
Monthly sales trend analysis.\ 
Region-wise sales comparison.\
Product-level performance insights. \
Segment-wise distribution (Consumer, Corporate, Home Office). \
Country-wise sales and profit tracking. \
Interactive filters for better exploration.
